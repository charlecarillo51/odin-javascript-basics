# The Odin Project - JavaScript Basics

Completed projects:
1. Rock Paper Scissors
2. Etch-a-Sketch
3. Calculator

Each project is contained in its own folder and can be opened independently.

## Run
These projects use plain HTML, CSS, and JavaScript. No npm installation is required.

Open each project's `index.html` in a browser:
- `rock-paper-scissors/index.html`
- `etch-a-sketch/index.html`
- `calculator/index.html`

## Submission
This folder can be uploaded to GitHub as one repository or the three project folders can be placed into a Google Drive folder.

## Notes
The projects are implemented without external libraries. The Calculator intentionally does not use `eval()` or `new Function()`.
